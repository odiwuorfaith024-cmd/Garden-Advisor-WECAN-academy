# Garden-Advisor-WECAN-academy 
Team The Hopeless and The Damned 


## What it does
AI chatbot for smallholder farmers who traditionally rely on advice from agrovets or other farmers who sometimes are not experts or up to date with agronomic information.
This AI chatbot provides real time guidance on crop management, soil health,weather and pest control, hence giving farmers a reliable place to ask questions, share images of their crops and receive guidance a structured library of expert agricultural knowledge.

## Setup
1. Clone: git clone <repo-url>
2. Create .env file with GOOGLE_API_KEY
3. Install: pip install -r requirements.txt
4. Run: streamlit run "Garden Advisor.py"
